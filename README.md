# Muhammad Ashar — Portfolio

Apple-inspired light-theme version of the personal engineering portfolio.

Upload the contents of this folder to the **root** of `asherahmedd.github.io` (preserve `assets/`, `projects/`, and `blog/`).

The homepage is responsive: compact mobile hero, swipeable project cards, and desktop three-card grid. The three existing project pages and the blog are included.

This ZIP does not include deprecated project filenames or client-specific copies.
