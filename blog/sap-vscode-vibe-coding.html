Vibe Coding in SAP ABAP Using VS Code and Claude Code

Exploring a more practical way to work with ABAP and CDS development using AI-assisted coding.

By Muhammad Ashar  ·  November 8, 2026

I've been exploring how AI-assisted coding can fit into SAP ABAP development, particularly when working with CDS views and custom ABAP developments.

Most of us working with SAP are familiar with Eclipse ADT and SAP GUI. But with tools like Claude Code becoming increasingly useful for development, I wanted to see how I could bring my SAP development workflow into VS Code.

The idea was simple: connect VS Code to an SAP system, access existing ABAP objects, and use Claude to understand and work with the code.

How I Set It Up

I used three main tools:

  • VS Code: My development environment.
  • ABAP FS (ABAP Remote Filesystem): Connects VS Code to the SAP ABAP repository using ADT services.
  • Claude Code: Helps analyze code, understand dependencies, and suggest developments.

The setup starts with installing the ABAP FS extension in VS Code and configuring a connection to the SAP system.

Once connected, I could browse ABAP objects and open CDS definitions directly in VS Code.

The interesting part comes when Claude enters the workflow.

Where MCP Comes In

Claude can understand ABAP code, but accessing objects from an SAP system requires tools.

That's where Model Context Protocol (MCP) comes in.

MCP provides a standard way for AI assistants to communicate with external tools. With a compatible MCP integration, Claude can request repository information through the available ABAP development tools.

The overall flow looks like this:

Developer → Claude Code → MCP Tools → ABAP FS / ADT → SAP System

One thing worth understanding is that connecting ABAP FS to VS Code doesn't automatically mean every Claude Code session has access to its MCP tools. That connection must be available to the AI client you're using.

What Can You Actually Do?

Let's say you're working with a custom CDS view.

Instead of manually going through its entire definition, you could ask Claude:

“Review this CDS view, explain the joins and calculations, and suggest where the logic could be optimized.”

You can also use it to understand existing ABAP programs, draft CDS changes, review SQL logic, or investigate dependencies.

Of course, AI-generated changes still need proper review, syntax checks, activation, and testing in SAP.

Is It Worth Exploring?

For me, the biggest advantage isn't simply generating ABAP code.

It's having an assistant that can help understand unfamiliar developments, explain complicated logic, and reduce the time spent investigating existing code.

There are still limitations, particularly around system connectivity, MCP configuration, and supported development operations. But even using it for code analysis and development assistance is useful.

If you're working with ABAP or CDS development and haven't explored VS Code with an AI coding assistant yet, it's worth experimenting with.
