Portfolio analytics privacy

The portfolio uses limited, cookieless first-party analytics to understand page visits, project interest, approximate active time and scrolling. Basic measurement runs automatically unless you opt out or your browser signals Do Not Track or Global Privacy Control.

Data collected

Random identifiers generated only in memory for the current page, page paths (without query strings), page visits, visible section durations, scroll thresholds, clicked project or blog links, technology filters, approximate device category, country and referring domain. The identifiers are discarded on navigation and cannot count unique people across page loads. Country is inferred by the receiving service, not used to identify individual visitors.

Optional analytics cookies

Separately from basic analytics, you can choose to allow recognition of repeat visits. Only after selecting Allow analytics cookies, this site saves a random browser identifier in a first-party cookie for up to 90 days. The server transforms it into a one-way digest and stores visit timestamps and whether a browser has visited before. It is not a person's name, LinkedIn identity or employer. Declining does not stop ordinary anonymous measurements.

The opt-in cookie remains on this browser for up to 90 days unless consent is withdrawn or browser data is cleared. Server-side visitor records expire after 90 days without a visit; event records are removed after 90 days. Withdrawing stops further repeat-visit measurement and deletes the local identifier, but already collected aggregate events remain until retention cleanup.

Not collected

No names, emails, typed chat questions, IP addresses in the analytics database, full browser fingerprints or session recordings. Browsers and hosting providers may maintain operational logs outside this custom database.

Storage and access

Events are stored in a Cloudflare D1 database and accessible through an administrator-token-protected API. Data is used only to improve portfolio usability. A persistent first-party browser cookie is set only after optional analytics-cookie consent; otherwise only privacy preferences are stored. Analytics data is deleted in accordance with the retention controls the site operator configures.

Your choice

Analytics is not necessary to use the portfolio. You can opt out at any time below; this choice persists in this browser until site data is cleared. A different browser or device requires a separate choice.
