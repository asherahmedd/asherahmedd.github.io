Portfolio analytics privacy

The portfolio uses limited, cookieless first-party analytics to understand page visits, project interest, approximate active time and scrolling. Basic measurement runs automatically unless you opt out or your browser signals Do Not Track or Global Privacy Control.

Data collected

Random identifiers generated only in memory for the current page, page paths (without query strings), page visits, visible section durations, scroll thresholds, clicked project or blog links, technology filters, approximate device category, country and referring domain. The identifiers are discarded on navigation and cannot count unique people across page loads. Country is inferred by the receiving service, not used to identify individual visitors.

Not collected

No names, emails, typed chat questions, IP addresses in the analytics database, persistent visitor IDs, cookies, full browser fingerprints or session recordings. Browsers and hosting providers may maintain operational logs outside this custom database.

Storage and access

Events are stored in a Cloudflare D1 database and accessible through an administrator-token-protected API. Data is used only to improve portfolio usability. No visitor identifier is stored in browser storage; the opt-out preference alone is stored in localStorage. Analytics data is deleted in accordance with the retention controls the site operator configures.

Your choice

Analytics is not necessary to use the portfolio. You can opt out at any time below; this choice persists in this browser until site data is cleared. A different browser or device requires a separate choice.
