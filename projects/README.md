## Page conventions

- Keep project titles, business context, architecture, and implementation scope accurate.
- Distinguish delivered features from conceptual architecture or proposed extensions.
- Use sanitized examples and representative metrics where real implementation data cannot be published.
- Refer to original SAP documentation for platform-specific behavior.
- Preserve navigation back to the [portfolio homepage](../index.html).

These pages are public project presentations; integrations, credentials, source mappings, and client-specific configuration are intentionally excluded.
