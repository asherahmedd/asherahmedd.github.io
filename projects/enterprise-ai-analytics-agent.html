01 / Project overview

Making enterprise analytics conversational.

Enterprise AI-Powered Analytics Agent is an enterprise conversational analytics initiative that helps users ask business questions in natural language and receive insights grounded in enterprise data. The technical challenge is not simply connecting an LLM to a database: it is providing consistent KPI definitions, controlled tool access and interpretable responses.

My work has focused on the SAP data and integration side: preparing analytics-ready views in SAP Datasphere, exposing governed data through service interfaces, and supporting tool-driven consumption by AI applications.

04 / Example workflow

An illustrative KPI request.

Consider a question such as: “What are our total sales?” The conversation layer interprets the intent, chooses an available analytical tool, calls a governed data service and returns a value with business context.

REQUEST → TOOL → DATA → RESPONSE
  1. Interpret the user's business question and identify the relevant metric.
  2. Invoke an approved tool with structured input rather than giving the model unrestricted database access.
  3. Read the metric from SAP Datasphere through an exposed service.
  4. Return the KPI with clear labels and business context.

This walkthrough is illustrative, uses no live customer values, and does not imply autonomous execution of business transactions.

06 / Engineering takeaways

What matters for enterprise AI.

  • Semantics come first. An AI experience is only as reliable as the definitions and data behind its tools.
  • Tools need boundaries. Service permissions and identity-aware authorization belong in the integration design, not in prompts alone.
  • Concurrency deserves testing. Request and user context must remain isolated when several conversations happen in parallel.
  • Explainability builds trust. KPI names, filtering context and transparent tool outputs make analytical answers easier to validate.
